# HurtMusic

Аудиоплеер для Windows со встроенным клиентом SoundCloud, прямым кэшированием треков на диск и плавающим оверлеем для игр.

## Архитектура и возможности

HurtMusic спроектирован для прямого воспроизведения потокового аудио и локальных коллекций без промежуточных серверов, телеметрии и региональных ограничений.

### Потоковый движок и кэширование
* **Прямой стриминг:** прямое воспроизведение каталогов SoundCloud (включая unreleased-материалы, ремиксы и сниппеты) через HLS-поток.
* **Локальное сохранение:** сохранение аудиопотока в стандартную папку пользователя (`Музыка/HurtMusic` или любой указанный каталог на диске). Файлы сохраняются с метаданными исполнителя, названия и обложкой JPEG.
* **Автономная работа:** сохранённые файлы доступны для переноса и воспроизведения в любых сторонних плеерах.

### Компактный оверлей (Gamer HUD)
* **Режим Always-on-Top:** плавающее окно размером 340×84 px фиксируется поверх полноэкранных игр без сворачивания приложения.
* **Минимальное влияние на процессор:** отрисовка индикатора воспроизведения и бегущей строки через аппаратное ускорение видеокарты.
* **Глобальные медиа-клавиши:** управление треками по системным клавишам клавиатуры и хоткею `Ctrl + Shift + M`.

### Обновления по воздуху (OTA)
* Фоновая проверка релизов через GitHub API.
* При выходе новой версии обновляется только исполняемый пакет (`app.asar`, ~37 МБ). Полная переустановка приложения не требуется.
* Автоматическое создание резервной копии (`app.asar.bak`) перед заменой.

### Спектральный анализ
* 64-полосный гармонический анализатор звука в реальном времени на базе Web Audio API.
* Адаптер интерфейса под нестандартные разрешения экранов (включая растянутый формат 4:3 / 1440×1080).
* Интеграция с Discord Rich Presence с отображением текущего трека и тайминга.

## Горячие клавиши

| Клавиша | Функция |
| :--- | :--- |
| `Пробел` | Воспроизведение / Пауза |
| `Ctrl + →` / `MediaNextTrack` | Следующий трек |
| `Ctrl + ←` / `MediaPreviousTrack` | Предыдущий трек |
| `Ctrl + Shift + M` | Переключение компактного оверлея (HUD) |
| `F` | Добавить в избранное |
| `↑` / `↓` | Громкость |
| `M` | Отключение звука |

## Запуск портативной версии

Программа поставляется в виде готового архива и не требует прав администратора или инсталляции:

1. Скачайте архив `HurtMusic-v1.0.0-win-x64-portable.zip` со страницы [Releases](https://github.com/hurters/hurtmusic/releases/latest).
2. Распакуйте архив в любую директорию.
3. Запустите `hurtmusic.exe`.

Настройки и сохранённые треки хранятся в профиле пользователя и не затрагивают системный реестр Windows.

## Сборка из исходного кода

```bash
# Клонирование репозитория
git clone https://github.com/hurters/hurtmusic.git
cd hurtmusic

# Установка зависимостей
npm install

# Запуск тестов безопасности и Range-парсера
npm test

# Запуск в режиме разработки
npm start

# Сборка дистрибутива
npm run build

# Создание релизного zip-архива
npm run pack:zip
```
